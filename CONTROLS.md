# Controls

| Input | Action |
| --- | --- |
| W / Up | Move north along the arena grid |
| D / Right | Move east |
| S / Down | Move south |
| A / Left | Move west |
| Space | Place one bomb; holding does not repeatedly plant |
| E / Left Shift | Character ability |
| Q | Pick up a bomb on your tile or directly ahead; press again to throw it |
| R | Cycle collected bomb types |
| F | Detonate owned remote bombs |
| Escape | Pause/resume |
| Tab (hold) | Scoreboard |
| Mouse | Menus, HUD ability button, pause |

Movement, bomb, ability, secondary, cycle and remote bindings can be changed in Settings. Arrow keys, Shift, Escape and Tab are reserved alternatives. Press a replacement key after clicking the binding. Assigning a key already in use swaps the two actions. Active game keys suppress browser scrolling. Moving and using an ability are temporarily locked during the countdown. Losing focus pauses the match and clears held inputs.

Movement is grid based: the diagonally viewed arena's north direction does not point exactly toward the top of the screen. Bombs block re-entry after leaving them. Find a corner outside the explosion cross, not merely a distant tile on the same line. Wood absorbs one normal blast; stone is permanent. Yellow world pickups apply immediately after their tile is clear of flames.

Free-for-All requires five eliminations; classic combat requires being the final survivor. If you lose in classic play, the bots finish the round and the results show the confirmed winner. Survival and Boss give the player multiple health points. Lava warning symbols brighten before activation, ice continues your current direction, and Orbital pads teleport to another generated pad.

The interactive tutorial keeps its opponent passive while you practice movement, planting, destroying the guaranteed nearby crate, collecting its pickup, and using an ability. The bot activates once a pickup and ability use have been recorded. Tutorial health starts at three. It can be replayed from How to Play.

Gold stairs connect the terrace floors. Ordinary blasts stay on their floor; thrown bombs can land on another floor. A carried fuse keeps ticking. Throw pickup extends toss distance from two to four tiles. Wading slows movement; bridges preserve normal speed. Water shortens lingering fire.
